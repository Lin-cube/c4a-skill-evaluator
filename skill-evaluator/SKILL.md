# C4 Skill Submission Evaluator

## 用途

给定一个包含 C4 技能提交的本地文件夹路径（通常从 WeChat 群下载），本技能自动
为每份提交做完整性与质量评审。可以把 TA 想象成一个自动助教：既检查作业是否
提交，又按评分表打分并撰写评语。

## 前置条件

### 运行时

- Python 3.8+（核心脚本仅用标准库，**无需 pip install**）
- 可选：`pip install pypdf` 以支持 PDF 全文解析（不装则 PDF 仅做文件名匹配）
- 可选（Level 3 LLM 深审）：设置 `OPENAI_API_KEY` / `OPENAI_BASE_URL`

### 输入

- 一个本地文件夹路径，含 C4 提交文件
- 文件遵循命名规范：`姓名拼音_C4_内容描述.扩展名`

## 工作流

### Step 1 — 扫描 & 识别作者

递归扫描目标文件夹，收集所有匹配 C4 模式的文件（文件名含 `_C4_` 或位于含 C4
的目录）。**作者提取链**（按顺序回退）：

1. 文件名 `_C4_` 前缀 → 作者名
2. 父目录名（若文件按作者分目录）
3. 标记为 `Unknown` 待人工复核

输出：`Dict[author, List[ScannedFile]]`，同时解析版本号 `_v2`/`_v3` 用于迭代追踪。

### Step 2 — 完整性检查（5 个必须文件）

对每位作者检查 C4 五个必须交付物。检测顺序：文件名精确命中（高置信度）→
扩展名 + 内容信号（低置信度）。每个文件只归入一个交付物，避免重复计数。

| 必须文件 | 检测信号 |
|----------|----------|
| Skill 说明文档 | 文件名含 `skill说明`/`skill_doc`/`说明`；或内容含"使用场景/输入/输出" |
| 可执行内容 | `.skill`/`.py`/含代码块或 YAML frontmatter 的 `.md` |
| Demo | `.mp4`/`.mov`/`.png`/`.jpg`/`.gif` 或文件名含 `demo/演示/截图` |
| 教学说明 | 文件名含 `教学/tutorial/teaching`；或内容含"上手/步骤/常见坑" |
| AI 日志 | 文件名含 `AI日志/AI_log`；或内容含"AI 工具/prompt/迭代" |

输出：每作者完整性矩阵（✅/❌）+ 命中文件 + 置信度。

### Step 3 — 质量评审（四条件）

对每份提交按 C4 四条件打分（规则层确定性评估；可选 LLM 深审增强定性判断）。

| 条件 | 检查要点 |
|------|----------|
| 可复用 | 有安装/环境说明？无硬编码绝对路径/密钥？列明依赖？ |
| 可执行 | 含可运行代码/workflow？frontmatter 完整？有执行入口？ |
| 可验证 | 有测试用例/示例？定义预期输出？成功/失败标准清晰？ |
| IO 明确 | 有"输入X，输出Y"一句话？输入输出类型清晰？边界情况说明？ |

每个维度：✅（≥2 项满足）/ ⚠️（1 项）/ ❌（0 项），并给出证据与改进建议。

### Step 4 — 生成报告

输出 Markdown 报告 + CSV 详表 + 可选 HTML：

1. **班级总览** — 提交人数、完整率、质量分布
2. **作者详情** — 完整性矩阵 + 质量分 + 评语 + 改进建议
3. **排名表** — 按综合分排序（可配置权重，默认 完整性×0.4 + 质量×0.6）
4. **全班改进建议** — 最常见缺失、最弱维度、自检建议

## 运行方式

```bash
# 基本用法（生成 Markdown + CSV 到 review_output/）
python c4_skill_evaluator.py <文件夹路径>

# 指定输出目录与格式
python c4_skill_evaluator.py test_data --output review_output --format md,csv,html

# 使用自定义评分表
python c4_skill_evaluator.py test_data --rubric references/c4_rubric.json

# 启用可选 LLM 深度评审（需 OPENAI_API_KEY）
python c4_skill_evaluator.py test_data --llm
```

## 边界情况处理

| 情况 | 处理 |
|------|------|
| 空文件夹 / 无 C4 文件 | 报告"未找到 C4 相关文件"，提示命名规范 |
| 文件名不规范 | 回退内容检测 + 目录名，标记"需人工确认" |
| 超大文件（>50MB） | 跳过内容分析，仅文件名/类型匹配 |
| 二进制（.mp4 等） | 仅文件名匹配，不读内容 |
| 同一作者多版本 | 识别 `_v2`/`_v3`，按最新版评审并展示迭代历史 |
| 中文文件名编码 | UTF-8 读取，GBK 回退 |
| docx | 标准库 zipfile+XML 提取正文；pdf 需 pypdf |

## 说明

本 SKILL.md 以 starter 脚手架为基座，补齐了四个层级的实现：
扫描（Level 1）、完整性检查（Level 2）、质量评审（Level 3）、完整报告系统（Level 4）。
核心创新在 Step 3 的"规则 + 可选 LLM"混合评审架构与可配置评分表（references/c4_rubric.json）。
